### 🧭 Journey

Grouped by the year each project started (first commit or earliest file date). Private repos are listed without links.

**2022: first steps in AI**
- [NeatPong](https://github.com/Asreonn/NeatPong): neuro-evolution (NEAT) teaching agents to play Pong. My earliest public code.

**2024: Python, data and first apps**
- TMS anomaly detection: autoencoder + heatmaps for a company project *(private)*
- Anime & manga recommendation scripts *(private)*
- First particle simulation experiments in Python *(private, later became [particle-sim](https://github.com/Asreonn/particle-sim))*
- [hotel-reservation-app](https://github.com/Asreonn/hotel-reservation-app): first Flutter app, a hotel booking demo (finished 2026)

**2025: ML research, simulations, hackathons and web tools**
- Hybrid DQN for dynamic feature selection: reinforcement-learning research and paper drafts *(private)*
- [particle-sim](https://github.com/Asreonn/particle-sim): emergent behaviour from simple particle rules (Python, NumPy, pygame)
- [flappy-bird-neat-visual](https://github.com/Asreonn/flappy-bird-neat-visual) and [algorithm-visualiser-suite](https://github.com/Asreonn/algorithm-visualiser-suite): NEAT and algorithm visualisers
- [city-watching-system](https://github.com/Asreonn/city-watching-system): FUZE'25 hackathon, a smart-city sensor dashboard
- [nasa-space-apps-exoplanet-hunt](https://github.com/Asreonn/nasa-space-apps-exoplanet-hunt): NASA Space Apps 2025, an ensemble view for exoplanet candidates
- [trivia-web-api](https://github.com/Asreonn/trivia-web-api): full-stack trivia platform (React + Express + MongoDB)
- [mathgame](https://github.com/Asreonn/mathgame): Flutter arithmetic roguelite
- [moonizer](https://github.com/Asreonn/moonizer): local-first CSV studio in TypeScript
- [noty](https://github.com/Asreonn/noty): cozy infinite-canvas notes app (React)

**2026: engines, games, apps and tooling**
- [pixel-physics-sim](https://github.com/Asreonn/pixel-physics-sim) → [pixelsim2-opengl](https://github.com/Asreonn/pixelsim2-opengl): C falling-sand engine, rewritten from SDL2 to OpenGL with chunking and multithreading
- [custom-engine-space-game](https://github.com/Asreonn/custom-engine-space-game) (C + raylib) → [godot-space-game](https://github.com/Asreonn/godot-space-game) and [minisurvivor](https://github.com/Asreonn/minisurvivor) (Godot 4.6)
- [dicedr](https://github.com/Asreonn/dicedr): visual decision-maker web game ([live](https://asreonn.github.io/dicedr/))
- [godot-superpowers](https://github.com/Asreonn/godot-superpowers): AI-assistant skills for Godot development
- [book-rental-app](https://github.com/Asreonn/book-rental-app): Flutter + Firebase store with an admin panel
- Client websites (e-commerce, catalogue, restaurant menu) with React + Supabase *(private)*
- Larger ongoing work: a Flutter RPG with AI narration, a tarot app, Godot simulation games, a voice-first desktop assistant (Tauri) and a self-hosted tech radar *(private, in progress)*
